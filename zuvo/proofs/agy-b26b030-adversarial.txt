ID: agy.py:279:reset-none-exhausted-forever
ISSUE: An unparseable `resetTime` gives `reset=None`. `known_life` only treats an account as recovered when `resetAt` is a number, so the stored low `life` never expires.
ATTACK VECTOR: Google returns RFC3339 with nanosecond fractions ("…:00.123456789Z"). On Python <3.11 `fromisoformat` raises `ValueError`, so `reset=None`. SUGGESTED FIX: Parse the reset time robustly (truncate the fractional part to 6 digits). If it still fails, record a fallback `resetAt` such as `now + N hours`, or give `known_life` a maximum age.
